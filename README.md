# Vigía de Motobross

Revisa cada 5 minutos que **app.motobross.shop** y **motobross.shop** respondan.

- Si un sitio no responde en 3 intentos seguidos, se abre un aviso con la etiqueta `caida`, con la hora y el tipo de error. GitHub avisa por correo.
- Cuando vuelve, el aviso se cierra solo con cuánto duró la caída.
- El historial de caídas queda en los avisos cerrados.

No contiene código ni datos de Motobross: solo hace una visita a cada página, como cualquier navegador.
